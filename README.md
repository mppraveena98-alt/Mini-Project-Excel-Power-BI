# Rapido Booking & Operations Analysis

A data analytics project based on 30,000 Rapido ride-booking records.

## Tools Used
- Microsoft Excel
- Microsoft Power BI
- DAX

## Project Overview
The project focuses on:
- Booking performance
- Booking value
- Cancellation analysis
- Incomplete rides
- Vehicle demand
- Location analysis
- Time-based demand
- Customer and driver ratings

## Process
1. Data cleaning and preprocessing in Excel
2. Data transformation and validation
3. DAX measures created in Power BI
4. Interactive dashboard development
5. Business insights and recommendations

## Key Insights
- 82.14% of bookings were completed
- 11.86% were cancelled
- 6% were incomplete
- Bike accounted for approximately 70% of bookings
- Late Night and Morning recorded the highest demand
- Customer cancellations were higher than driver cancellations

## Dashboard

Power BI dashboard analyzing Rapido booking and operational performance.
